# Private-alternative

> A curated list of privacy-focused and security-respecting alternatives to mainstream digital services.

--- 

# About this repo 

This repository aims to help you take control of your digital footprint by substituting telemetry-heavy and ad-driven products with privacy-first alternatives. 

Whether open-source or proprietary, every tool listed here prioritizes end-to-end encryption, minimal data collection, or user sovereignty.

---
